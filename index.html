Estimating a person’s pace of aging from a single blood draw

I built QueryGaP because I was tired of digging through dbGaP documentation by hand. It indexes 3,000 studies and 450,000 variables with hybrid search and an agent. Researchers can use it through a public web app or directly from ChatGPT and Claude via MCP.

Forecasting reasoning length from model internals

I built a 10,000-prompt benchmark to test whether an LLM’s internal state after reading a prompt predicts how long its response will be before generation begins.

On 1,000 untouched Qwen3/OASST2 prompts, a frozen state model averaged 169 fewer tokens of absolute error than a strong text-only ensemble (95% CI: 129–209).

Keeping coding agents away from sensitive files

I wanted a way to use coding agents around sensitive research files without relying on the model to behave. I modified OpenCode so agent commands run as a restricted Unix user, letting filesystem permissions—not the agent—decide what it can read.

Can language-model agents find Nash equilibria?

I built repeated-game environments to distinguish two explanations: are language models reluctant to act selfishly, or do they struggle with strategic reasoning? They did pursue competitive equilibria; as games became harder and less familiar, additional inference-time reasoning mattered more.

Scaling a model of shared genetic risk to UK Biobank-sized data

For my Cambridge dissertation, I derived a mean-field variational inference algorithm for Latent Factor Allocation, a Bayesian model of shared genetic risk, making it tractable at UK Biobank scale. I implemented it alongside a partially collapsed Gibbs sampler in NumPy and SciPy.
